# 历史列表分页响应隔离

日期：2026-10-25。基线：`98a261338bf12694eb1c5d2e0867cbe7d4800004`。

## 复现与修复

历史列表原先只在响应后核对会话 ID。同一会话翻页时，旧页晚返回可覆盖新页；重置保留 ID，旧列表会在重置后再次显示。失败响应没有过期检查，会覆盖当前操作提示。连续点击同一翻页按钮会重复请求相同 offset；已经移除的记录按钮仍可发起旧记录查询。

现在每笔分页查询捕获请求代数、会话切换代数、会话 ID 与 epoch，只有最新有效请求才能更新列表、页码、offset 和按钮。相同目标页的有效在途请求去重，旧请求结束只能释放自己的标记。会话切换期间阻止历史查询和打开记录，清理会话结果时同时使历史请求和旧列表失效。

请求身份与已显示页面身份分开保存：导航失败不更改原页，仍可打开当前显示的记录，重试继续请求原目标页。记录按钮只在其原页仍显示、会话匹配且没有切换时可用。重置成功后旧按钮失效，但主动重新加载历史仍能读取重置前保存的快照。
