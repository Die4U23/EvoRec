## 浏览器续验（2026-09-28）

- 使用独立 PostgreSQL schema、127.0.0.1:8766 API 和 103 件临时合成商品。在真实浏览器逐页点击后，六页分别显示 1–20、21–40、41–60、61–80、81–100、101–103 件；末页“下一页”禁用。返回上一页后显示 81–100，点击刷新回到 1–20。
- 同一隔离实例的 HTTP 检查：`offset=0&limit=100` 返回 100 件，`offset=100&limit=100` 返回 3 件，`offset=103&limit=100` 返回空列表；负 offset 与超过 100 的 limit 均返回 422。仅导入未发布时 `/health/ready` 返回 503。
- 另以无数据库的 24 件内存演示商品核对页面：第一页 20 件、第二页 4 件。首次打开隔离页面时浏览器曾显示旧缓存；显式刷新后才显示新版翻页控件，因此现有运行中的 `/app` 标签也应刷新，旧服务进程则需重启。
- 验收后关闭两个新建标签页和服务进程，删除 103 件合成商品所在的唯一临时 schema 与临时启动脚本；开发数据库未修改。本轮没有重新执行导入/构建/发布浏览器全链路，也没有补齐持久校验任务或多 worker/生产验收。
