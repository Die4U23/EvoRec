# 商品目录分页与变更后刷新

日期：2026-10-25。基线：`d033fd3966a6813aa529327d2452bb5acb0971d5`。

## 现象与定位

目录查询响应未检查是否仍属于最新请求。翻页未完成时刷新首页，旧分页晚返回会覆盖首页；下架后的刷新已显示“已下架”，更早的首页查询晚返回又会显示“可用”。迟到错误也会覆盖当前提示。重复点击翻页会多次查询同一 offset，旧请求完成后还能使后续点击使用错误的页码。

## 修复

每次读取分配递增请求代数，只有最新请求能更新商品缓存、会话标题、列表、页码及导航按钮，旧错误直接忽略。在途标记由所属请求清理，旧请求不能释放新请求的保护。相同目标页的导航点击合并；显式刷新以及导入、下架、发布后的刷新总是新建读取，避免复用变更前的状态。查询成功才更新 offset，失败保留已显示页面供原位置重试。
