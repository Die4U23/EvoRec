## 独立 R06 推荐入口

前提：本机 PostgreSQL 可连接且用户能创建 schema；已按[服务接入指南](../../research/R06-multi-interest-guide.md)准备完整的批准包，并安装 Python 3.12 的可选 NumPy 服务环境。下面路径和摘要是本机已验收的包身份，不代表首次克隆就自带模型；模型、原始数据和凭据仍不入 Git。`.venv-accelerated` 的创建与依赖安装按该指南执行，不能用只有服务依赖的 `.venv` 冒充 NumPy 环境。

在项目根目录打开 PowerShell，读取已有 `.env` 的数据库配置，不打印密码、不执行 `.env` 内容：

```powershell
$demoDbLine = Get-Content .env | Where-Object { $_ -match '^EVOREC_DATABASE_URL=' } | Select-Object -First 1
if (-not $demoDbLine) { throw '缺少 EVOREC_DATABASE_URL' }
$env:EVOREC_DATABASE_URL = $demoDbLine.Substring(20).Trim().Trim('"').Trim("'")
.\.venv-accelerated\Scripts\python.exe -m scripts.run_r06_demo `
  artifacts/demo/r06-first-run artifacts/bundles/r06-frozen-20261004-a `
  bfe57ed8-3f6f-429d-ba07-b64b2ab1aeec `
  --expected-manifest-sha256 9d622c95841027175779b19cbda5e1f0923c574c45d5daa4dab8a84ed8691ca6 `
  --backend numpy
```

等待终端出现 `status: ready`，打开其中随机 loopback 地址的 `/app`，不是既有 8000 页面。选择示例用户或新用户，点击“开始体验”，再选择受控稠密模型；核对实际策略、商品包和模型版本。示例历史固定为批准包顺序中首个具有非零向量的训练商品，本包为 `0060501960`，不是测试目标、真实用户或为效果筛选的画像；新用户历史为空。详情、收藏、屏蔽与撤销会持久写入本轮隔离 schema；R06 完整已见集合仍保留撤销前的反馈，重置 epoch 后才清除本轮排除效果。固定种子下架或表示变动时返回明确 409，不悄悄换一个种子。

这是**临时、安全隔离的推荐演示**，不是业务部署：每次创建新 `test_evorec_<随机 UUID>` schema；管理员能力关闭，不修改业务 schema、活动模型或现有 8000 服务。未启动后台 comparison worker；后台任务、新品内容基线和结果页不是这个入口的交付承诺，不能把任意新商品塞进旧 R06 权重。`ready.json` / `stopped.json` 是生命周期记录，不是通过报告。

按 Ctrl+C 正常退出，等待 `stopped.json` 中 CPU 清退和自有 schema 删除确认；也可在本次输出目录创建空 `stop` 文件请求正常关闭。正常退出删除的是本轮临时演示数据，无法恢复；希望保留业务数据应使用原持久服务配置。强杀/断电不能保证退出或清理，需根据本次 `owned.json` 核对确切自有 schema，不能批量删除所有测试 schema。输出目录必须从未存在；再次演示请换一个新目录名，不覆盖旧记录。显式端口可通过 `--port` 指定，8000 一律拒绝。

自动真实 HTTP 复验使用 `python -m scripts.verify_r06_http` 和同一组包参数，另选新输出目录；要求干净 Git 提交，归档关键源码，只在进程正常退出且数据库 namespace 恢复后写通过报告。客户端等待 10 秒不改变服务端原有 2 秒请求期限。当前 NumPy 完整包已通过，标准库完整非空示例历史、持续负载、独立进程重启重放与 SLA 仍未在此入口验收；已有合成 TCP 和旧 ASGI 恢复记录分开保留。

## 本轮基线口径

冻结 R06 已有的热度来自训练期评分不低于 4 的事件，使用 365 天半衰期、在训练截止点固定；热门分数直接使用已批准的衰减计数，不是点击概率、实时热度或纯原始次数。召回融合所用的对数归一化值仍保持原样，不能因浮点归一化压平差异而改变热门顺序。修复只复用批准的统计，不重训、不改权重或已保存结果。与研究 PRD 的纯频次 Popularity 应区分命名，不能冒称已完成该基线的官方复现。

R06 的 `adaptive` 当前是固定 dense 别名；其他演示路径可能明确回退热门，不是已实现的预算路由。策略对比不因此多出一种独立算法。

模型产物身份保持不变，但修正后的新热门请求会与旧代码输出不同。已保存结果按原记录重放，不将跨代码版本的新计算冒称逐字相同；新输出使用独立候选来源标签。
