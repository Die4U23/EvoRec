# R05：时间滚动模拟冷商品与神经候选排序

登记：2026-09-16，尚未生成或查看 R05 验证 / 测试结果。配置见 [r05-ranker.json](../../research/configs/r05-ranker.json)。

## 数据与边界

查询用户固定采用原用户哈希规则模 20 余数 3，排除 R01 开发用户，并验证与 R02 / R03 / R04 用户不重合。训练数据来自 R03 用户的训练期交互，严格早于 1628643414042。R05 早期交互只用于请求历史，不用于参数拟合。商品与时间区间仍有重合。

重新拟合一个 128 维 TF-IDF / SVD 编码器，拟合文档仅为 R03 用户在 2017-01-01 前正反馈商品的标题与类别，随后冻结。静态快照缺乏历史字段版本的限制仍然存在。这个较早编码器避免模拟冷商品目标参与文本词表 / IDF / SVD 的拟合；后续商品只做冻结转换。

## 时间滚动训练

两个窗口为 [2017-01-01, 2020-01-01) 与 [2020-01-01, 原训练截止)。每个窗口的热门、协同统计和模型已见商品集合仅使用窗口开始前的 R03 交互。窗口内按严格时间顺序构建历史，同时间事件先形成请求，再一起更新历史。

每个窗口最多 12,000 个有历史的正反馈请求，按 query_id 的固定 SHA-256 排序截取，采样规则不读取召回是否命中。目标不在窗口统计训练商品集合时属于模拟冷商品。仅对目标真实进入候选池、且历史可以表示的请求形成排序损失；候选未命中数量与冷目标覆盖单独报告，禁止向候选池插入答案。

## 候选与新模型

每个请求使用协同融合 Top200 与固定内容 Top200 的去重并集，最多 400 件。主基线与两个学习方法共享这个池，输出最多 200 件；因此最终 Recall@200 可以变化，但池本身的目标可达性不因排序变化。没有可表示历史时保持基线列表。

模型为残差 MLP 排序器，输入用户内容向量、候选内容向量、逐元素乘积、绝对差，以及候选的召回名次、训练热门强度、模型冷标记、商品年龄、历史数量和内容一致性。没有商品 ID 嵌入，不输入目标、未来评分或测试命中。使用固定 RRF 分数作为初始排序，再学习有界残差。

在候选池内用单正目标 softmax 交叉熵训练。未观测候选只是对比负样本，不代表用户明确不喜欢。比较两种已登记设置：普通样本权重 1；模拟冷目标样本权重 4。学习率 0.001、最多 15 轮、连续 4 轮验证 NDCG@10 未提高时早停。先运行种子 17 的两种设置，然后为验证 NDCG 最佳的神经设置训练种子 29 / 43。

## 验证选择与最终测试

每个训练过程只按整体验证 NDCG@10 保存最佳检查点。对原 RRF 和种子 17 的两种神经模型进行最终方法选择：整体 NDCG 至少达到 RRF 的 97%，然后比较冷商品 Recall@20；同分比较整体 NDCG，再优先原基线与声明顺序。允许保留基线。

为区分“训练目标消融”与“多种子”，报告种子 17 的两个训练目标，以及所选神经设置的三种子均值 / 样本标准差。最终默认方法与用于多种子研究的神经设置分别记录，不把神经均值自动称为被选中的上线方法。

测试集仅在训练、检查点和方法选择全部冻结后开启。所有正反馈事件保留在整体分母；同时报告模型冷且可用、有历史、冷用户等分组，以及原始 400 候选池的可达率。可额外报告冻结 R03 seed 17 双塔融合参考，但其编码器和召回池不同，不作为纯排序消融。

## 验收与展示

保存数据、早期编码器、每个滚动窗口的统计截止与训练样例证据、候选池、特征指纹、逐轮损失 / 验证指标、检查点与测试轨迹。核对训练时点、用户隔离、目标未注入候选池、候选合法性和重载一致性。

结果无论提升或退化都写入报告与博客。新的训练与图表单独放在 R05，保持 R02 / R03 / R04 历史证据。当前没有线上性能结论，也不把候选排序当成学习型预算路由。
