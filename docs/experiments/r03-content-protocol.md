# R03 内容召回辅助实验：预先固定的协议

登记：2026-09-15，在查看本轮验证 / 测试指标之前。配置见 [r03-content.json](../../research/configs/r03-content.json)。

本轮回答两个问题：商品内容能否为训练交互未覆盖的商品提供候选入口；学习用户与商品的内容表示，能否优于固定内容相似度。当前实验不是原 SASRec 模型的续训，而是增加可供后续融合的内容路径。

## 新用户样本

继续使用官方 Video_Games 全量 0-core 交互，从 sha256(evorec-r02-v1|user) 的前 8 字节大端整数模 20 等于 1 的用户中取全部记录，并排除 R01 的开发用户。R02 使用余数 0，因此用户不重合。商品和日历区间仍与之前实验重合，不能宣称跨时间或跨领域泛化。

训练截止 1628643414042，验证截止 1658002729837，单位 Unix 毫秒。较早交互形成历史，相同时间戳批量更新。评分至少 4 为正反馈，过滤所有已交互商品；主指标分母保留全部正反馈事件。首次观察严格早于请求作为可用性代理。

## 元数据与时间边界

来源：[Amazon Reviews 2023 官方商品元数据说明](https://amazon-reviews-2023.github.io/main.html)。仅允许商品 title 与 categories 进入编码器，不使用评论文本、平均评分、评分数量、价格、关联购买、图片或测试标签。缺失内容保留缺失状态，不能用 ID 拼成假文本。

元数据是 2023 年采集的静态快照，未提供这些字段的逐版本时间戳。因此，本轮假设“商品可用时其静态标题与类别可以被读取”，仅用于辅助内容实验。这不能证明历史时刻真实可见内容下的收益；时间上架代理仍不是实际商品上架记录。

文本词表、IDF 与 SVD 仅在所选用户训练正反馈涉及的商品内容上拟合。完整类别只执行 transform，未见商品的新词不会进入已冻结词表。保留缺失和词表外商品统计。

## 方法与预算

固定参照为 Popular、365 天半衰期 RecentPopular、CF-blend-a0.25。所有参照在本轮训练样本重建，不加载 R02 的拟合统计。

内容基线采用词 / 二元词 TF-IDF（最多 20,000 特征、min_df=2）和训练商品上拟合的 128 维 SVD，L2 归一化。用户表示为历史内容向量按 0.8 衰减的加权均值。商品检索采用精确余弦排序，先过滤可用性、缺失内容和已交互集合，再输出最多 200 个候选。无有效内容历史时显式回退到近期热门。

增加双塔 MLP：用户加权历史向量与商品内容向量分别进入带残差的两层投影，使用训练正反馈词表上的完整 softmax 交叉熵。两种学习率 0.001 / 0.0003，隐藏维 128、温度 0.1、batch size 256，最多 12 轮、patience 3。先在种子 17 选学习率，再运行 29 和 43，每次按验证 NDCG@10 选检查点。固定文本编码器不随神经种子重新拟合。

融合采用两路已合法化 Top-200 的加权倒数排名融合，常数 60；内容权重预先定为 0.25 / 0.5。选型只读取验证集。纯内容与融合结果都保留，避免用整体指标掩盖冷商品可达性。

## 验证与交付

比较 NDCG@10、Recall@20、候选 Recall@200、覆盖率与五类有效样本。额外检查：内容可表示目标数、有内容历史请求数、模型冷且可用商品的命中，以及候选中冷商品数量。分组相互重叠，不能相加。

测试只在固定内容编码器、全部模型检查点和融合参数选择结束后开启。本轮测试查看后不继续针对它调参。记录源文件哈希、代码快照、文本编码器、检查点和逐请求轨迹；核对重载结果，三种子报告均值与样本标准差。没有进行统计显著性检验时不宣称显著优于。

结果与图表放在 docs/experiments/r03-content/；R02 报告原样保留。在线推荐、商品发布、C++ 性能优化与预训练语言模型编码仍不属于本轮实现。

技术依据：[TF-IDF](https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html)、[TruncatedSVD](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.TruncatedSVD.html)。TF-IDF/SVD 是统计文本表示，双塔投影是神经模型；不将其描述为预训练大语言模型。
