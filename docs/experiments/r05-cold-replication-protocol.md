## 统计分析集合

三种子各自以及三个固定种子的“逐请求指标平均”分别对照 RRF、CF-blend；分组为全部正反馈、有历史请求、模型冷且可用目标；指标 NDCG@10 与 Recall@20，共 48 组差值区间。

三个种子的指标平均不是集成模型的推荐结果。跨种子均值和样本标准差单列；用户重采样区间不包含训练随机性。

从原始 R05 样本恢复 query_id→user 映射，核对同一查询的时间、目标、历史和冷标记。按分组中出现的用户整体有放回重采样，同一用户所有请求与所有方法一同进入抽样。每次保留请求加权口径：指标差值总和 / 请求数，而不是用户均值再平均。

固定 bootstrap seed=20260916、10,000 次，percentile 95% 边际区间；点估计为原请求平均差值。所有比较均报告，不筛选“显著”的条目。48 组区间不是同时置信区间，跨零与否不构成多重比较校正后的总体检验；不输出“证明算法有效”的结论。

用户聚类只处理用户内相关性，不处理跨用户的共同商品、时间冲击，也不能补救测试后提出假设的选择偏差。方法背景见 [Cameron 与 Miller 的聚类推断综述](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015.pdf)。
