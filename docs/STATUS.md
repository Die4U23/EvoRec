## 2026-09-16 R05 新排序模型训练

新留出样本 223,805 条交互、136,953 名用户，与 R01–R04 用户不重合，协议 2624e6561e71af4b。排序训练只使用 R03 原训练期内的两个滚动窗口；TF-IDF / SVD 仅拟合 2017 年前的 15,824 件正反馈商品文本。

两个窗口共 21,287 个有历史采样请求，实际 3,851 个目标进入合法候选池并形成损失，其中 564 个为模拟冷目标。模型为 520 → 128 → 64 → 1 残差 MLP，无可训练 ID 嵌入。比较普通权重 1 与冷目标权重 4，候选未命中不注入答案。

完成 4 次 GPU 训练、35 轮。ListMLP-s17 / ColdListMLP-s17 / ListMLP-s29 / ListMLP-s43 的最佳轮次为 3 / 3 / 8 / 5；全部检查点重载后的完整验证指标一致。普通模型按验证 NDCG 获得额外种子；最终按整体质量下限和冷召回选中 ColdListMLP-s17。

测试共 12,720 个正反馈、7,088 个模型冷且可用目标。RRF / 普通 seed 17 / 冷加权 seed 17 的 NDCG 分别为 0.006537 / 0.009426 / 0.009119，冷目标命中分别为 6 / 11 / 26。冷加权对同候选池 RRF 的观测差值为 +39.5%；在该次原运行中冷加权只有一个种子；后续复验见上方新增记录。普通模型三种子 NDCG=0.009546 ± 0.000315，不能将此标准差套给冷加权模型。候选池只有 127 个冷目标可达。

**验证：** 服务环境 96 项通过、3 个神经模块因缺依赖跳过；研究环境 28 项通过，其中 8 项门控检查与服务套件重复。独立审计通过 182,771 条排序记录、36,554,200 次排名候选检查、45,580 个候选池及全部训练样例；另外检查 15,220,569 个池候选和 28,144 行缓存特征。召回排名未在审计中全部重新推理，来源由保存代码、指纹和目标隔离测试约束。
